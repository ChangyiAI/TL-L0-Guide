
### 3.3 签字怎么做（做法 A）

1. 导引技能生成待签包，推送"包编号＋文书类型＋指纹码＋一句话摘要"。你在电脑或手机上阅读（手机经 ChatGPT 的 Remote 连接本机）。
2. AI 请求运行 `tl sign <包编号> 确认`（或 `tl sign <包编号> 退回 --reason "<一句理由>"`）。签字目录在沙箱之外，Codex 必须弹出批准框。
3. 你核对批准框里的**包编号**和**确认/退回**，点"**仅本次批准**"。

签字命令先核对清单里每个文件的当前指纹是否与清单一致，一致才写入，并自动记下指纹码。你全程只做两件事：**核对包编号，点仅本次批准**。

### 3.4 什么时候签字作废

以下两处由检查脚本复核（M15）：

- **每一步推进前**：签字有效、指纹码一致、待签包内文件与当前文件一致。
- **签字之后**：正文或任一受审附件被改动或替换，签字即作废，要求重新生成待签包、重新签。

### 3.5 设置（实测③要验证的就是这一节）

| 项 | 设置 |
| :-- | :-- |

| Codex | 沙箱模式"工作区可写"，Windows 沙箱用 elevated；审批策略"按需审批"；审批人为"用户"，**不开自动审查** |
| Claude Code | 岗位在云会话中运行，物理上接触不到签字目录（D-206①） |

| 手机 | 设锁屏密码；遗失即在电脑"设置 → 连接"里移除 |
| 补充措施（不作唯一保护） | 钩子拦截对签字目录的写入尝试；任务后改动比对（D-173） |
