## 2. 命名规则（D-208）

| 对象 | 规则 | 例子 |
| :-- | :-- | :-- |
| 仓库名、本机顶层目录、组织名 | 首字母大写；仓库名取 `TL-L<层>-<名称>` | `TL-L0-Guide`、`D:\Tianlong\`、`C:\TianlongSign\`、`ChangyiAI` |
| 仓库内部目录、机器读写的文件 | 全小写英文，单词以连字符相连 | `src`、`acceptance`、`progress.json` |
| 任务编号、包编号 | 全小写 | `qf-001`、`qf-001-g1-01` |
| 工具规定须大写的文件 | 保持原样 | `AGENTS.md`、`CLAUDE.md`、`README.md`、`SKILL.md` |
| 给人读的文书 | `编号_中文名.md` | `01_需求确认书.md`、`02_门1确认单_规程包建造_v1.md` |
| 正本文件（④） | `号段_中文名_v版本.md`（版本中的点写成下划线） | `10_传统软件生产工艺SOP_v3_11.md` |

## 6. 项目仓库统一骨架（规程包启用后，D-208）

```text
<仓库名>/
├── AGENTS.md  CLAUDE.md  README.md  Makefile
├── .agents/skills/        # Codex 读取的施工技能（生成件）
├── .claude/               # agents/、rules/、skills/（生成件）、settings.json
├── .specify/              # SpecKit 规格链
├── .tianlong/
│   ├── pkg/               # 规程包装入件：git 子模块，钉在已批准版本，只读
│   └── work/<任务编号>/    # 运行记录：progress.json、assumptions.jsonl、forms/、packages/
├── docs/
│   ├── contracts/registry.md          # 接口登记表
│   └── intake/{raw,converted,index}/  # 资料入库三层
├── src/                   # 业务代码
└── tests/                 # 测试
```

**写入规则**：业务代码与测试只进 `src/`、`tests/`；运行记录只进 `.tianlong/work/`；`.tianlong/pkg/` 与生成件只读。
