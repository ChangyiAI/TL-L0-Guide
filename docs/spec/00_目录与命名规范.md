# 00_目录与命名规范（v0.1，2026-09-27）

> **性质**：规程包内的装机细节文件（D-099 收录边界）。正本规则见 `10` 卷三 C（D-208）；本文件补充组织名、本机路径与既有仓库登记。
> **适用**：所有在天龙仓库中新建目录或文件的人与 AI。新增仓库顶层目录，须先在本文件第 4 节登记。

## 1. 托管与本机

| 项 | 规定 |
| :-- | :-- |
| GitHub 组织 | 登录名 `ChangyiAI`；显示名称"长忆智元（北京）科技有限公司"；全部仓库为私有库 |
| 本机仓库根 | `D:\Tianlong\`（无 D 盘时用 `C:\Tianlong\`）；每个仓库一个文件夹，名称与 GitHub 仓库名完全相同；不放 OneDrive 等同步盘 |
| 签字记录 | `C:\TianlongSign\<仓库名>\signatures.jsonl`，在一切仓库之外 |
| 仓库关系 | 本机为主库；GitHub 为远端灾备与交接通道；不在 GitHub 上合并；合并只允许快进（D-206②） |

## 2. 命名规则（D-208）

| 对象 | 规则 | 例子 |
| :-- | :-- | :-- |
| 仓库名、本机顶层目录 | 首字母大写；仓库名取 `TL-L<层>-<名称>` | `TL-L0-Guide`、`D:\Tianlong\`、`C:\TianlongSign\` |
| 仓库内部目录、机器读写的文件 | 全小写英文，单词以连字符相连 | `src`、`progress.json`、`acceptance` |
| 任务编号、包编号 | 全小写 | `qf-001`、`qf-001-g1-01` |
| 工具规定须大写的文件 | 保持原样 | `AGENTS.md`、`CLAUDE.md`、`README.md`、`SKILL.md` |
| 给人读的文书 | `编号_中文名.md` | `01_需求确认书.md` |

## 3. 项目仓库统一骨架（D-208）

```text
<仓库名>/
├── AGENTS.md  CLAUDE.md  README.md  Makefile
├── .agents/skills/        .claude/        .specify/
├── .tianlong/
│   ├── pkg/               # 规程包装入件（git 子模块，只读）
│   └── work/<任务编号>/    # 运行记录：progress.json、assumptions.jsonl、forms/、packages/
├── docs/
│   ├── contracts/registry.md
│   └── intake/{raw,converted,index}/
├── src/
└── tests/
```

写入规则：业务代码与测试只进 `src/`、`tests/`；运行记录只进 `.tianlong/work/`；`.tianlong/pkg/` 与生成件只读。
