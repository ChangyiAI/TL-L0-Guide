## D. 签字门加固（实测③后新增，装机必做）

> 实测③发现：签字目录建在 C 盘根下时所有登录账户可写；被加入 Codex 项目源文件夹时，Codex 每次启动任务都会开放它的写权限；工作区里的项目级 `.codex` 配置可被 AI 写入。以下各步由 Fred 本人执行，**不交给 Codex**。组合脚本未整体实测，各组成命令已在实测③中验证。

| # | 做什么 | 怎么确认做对了 |
| :-: | :-- | :-- |
| D1 | **源文件夹**：Codex 编辑项目，源文件夹只保留 `D:\Tianlong`，移除签字目录；改动后此前建立的任务一律停用，另开新任务 | 新任务里 `whoami` 为沙箱账户，随后 `icacls C:\TianlongSign` 不变 |
| D2 | **查两个编号**（每台电脑不同）：在 Codex 新任务运行 `whoami /groups`，记下 `CodexSandboxUsers` 的编号（沙箱组）；运行 `icacls D:\Tianlong`，记下 Codex 自动加上、显示为一串编号并带 `(M)` 的那一项（沙箱访问身份） | 两个编号都已记下 |
| D3 | **签字目录权限**：管理员 PowerShell 执行下方脚本 1 | 输出 6 行：沙箱组 `(DENY)(DE,WD,AD,WEA,DC,WA)`、SYSTEM 与 Administrators 完全控制、Users 只读、liufd 可修改、沙箱访问身份 `(RX)` |
| D4 | **项目级配置目录**：管理员 PowerShell 执行下方脚本 2，为 `D:\Tianlong` 和其下每个仓库预建 `.codex` | 每个 `.codex` 首行为沙箱组 `(DENY)`，所有者为 liufd |
| D5 | **复查**：Codex 新任务运行 `whoami` 后，再查 `icacls C:\TianlongSign`；在该任务中尝试 `Set-Content C:\TianlongSign\x.txt "t"` 与写 `D:\Tianlong\TL-L0-Guide\.codex\config.toml` | 权限不变；两次写入均被拒或弹框（点拒绝）；文件不存在 |

**要点**：受保护的目录必须由 Fred 本人建立，所有者设为 liufd——所有者是沙箱账户时，沙箱能自己删掉规则；所有者是管理员组时，Codex 刷新沙箱会报错、连命令都启动不了。DENY 用 PowerShell 设置，不用 icacls：icacls 设"禁止写入"时会一并禁掉"同步"权限，沙箱连目录都读不了。

脚本 1（签字目录；把两个编号换成 D2 查到的值）：
```powershell
$d = 'C:\TianlongSign'
$g = New-Object System.Security.Principal.SecurityIdentifier('<沙箱组编号>')
$c = New-Object System.Security.Principal.SecurityIdentifier('<沙箱访问身份编号>')
icacls $d /setowner 'THINK66\liufd' /T /C
icacls $d /inheritance:d
icacls $d /remove:g *S-1-5-11
$acl = Get-Acl $d
$acl.PurgeAccessRules($g); $acl.PurgeAccessRules($c)
$w = [System.Security.AccessControl.FileSystemRights]'WriteData, AppendData, WriteExtendedAttributes, WriteAttributes, Delete, DeleteSubdirectoriesAndFiles'
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule($g, $w, 'ContainerInherit,ObjectInherit', 'None', 'Deny')))
$acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule($c, 'ReadAndExecute', 'ContainerInherit,ObjectInherit', 'None', 'Allow')))
Set-Acl -Path $d -AclObject $acl
icacls $d /grant 'THINK66\liufd:(OI)(CI)(M)'
icacls "$d\*" /reset /T /C
icacls $d
```

脚本 2（项目级配置目录；按实际仓库增减路径）：
```powershell
$g = New-Object System.Security.Principal.SecurityIdentifier('<沙箱组编号>')
$w = [System.Security.AccessControl.FileSystemRights]'WriteData, AppendData, WriteExtendedAttributes, WriteAttributes, Delete, DeleteSubdirectoriesAndFiles'
foreach ($p in 'D:\Tianlong\.codex', 'D:\Tianlong\TL-L0-Guide\.codex') {
  if (Test-Path $p) { Remove-Item $p -Recurse -Force }
  New-Item -ItemType Directory -Path $p | Out-Null
  icacls $p /setowner 'THINK66\liufd' | Out-Null
  $acl = Get-Acl $p
  $acl.AddAccessRule((New-Object System.Security.AccessControl.FileSystemAccessRule($g, $w, 'ContainerInherit,ObjectInherit', 'None', 'Deny')))
  Set-Acl -Path $p -AclObject $acl
  icacls $p
}
```

本机（THINK66）实测值：沙箱组 `S-1-5-21-3872341309-1409660839-451377076-1002`；沙箱访问身份 `S-1-5-21-649615720-2133938906-1632291455-2943680807`。
